# 请求受理、幂等与执行事务｜内容大纲

从一个具体场景展开：顾问提交条款查询，等待过程中网络断开。他再次发送同一请求。服务需要给出明确答案：这是原命令的重放，还是新的用户回合？本篇沿实际 HTTP 入口和数据库事务，解释一次请求怎样成为可追踪的后台任务。

对应正文：[用户点击发送之后：请求受理、幂等与执行事务](../03-request-admission-and-transactions.md)。
