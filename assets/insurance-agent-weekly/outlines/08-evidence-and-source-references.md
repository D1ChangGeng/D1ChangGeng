# 证据身份、来源引用与多跳查询｜内容大纲

从一个需要跨产品查证的咨询问题开始。模型要取得产品身份、检索条款、读取原始页，再合并结论。本篇研究这些工具如何共享稳定身份，以及当前主体为什么能够读取某一页。

对应正文：[从检索片段到原始条款：证据身份、来源引用与多跳查询](../08-evidence-and-source-references.md)。

## 01｜找到几段相关文字，怎样进一步回答跨产品问题？

区别候选召回、限定范围内的枚举和完整业务结论。建立产品目录→检索→来源页的贯穿案例，并说明多跳参数来自上一步结果。

## 02｜产品、文档、片段与 Evidence 分别是什么？

展示 productId、documentId、chunkId、evidenceId 和物理页的实际形状。说明同页多片段、版本变化与索引重建的影响。

## 03｜一份工具结果怎样携带证据和缺口？

使用真实搜索结果 Schema 展示元数据、评分、来源集合和 provenance。区分 null、partial、unknown 和完整业务覆盖。

## 04｜SourceRef 是什么？为什么模型只传递一个引用？

展示不透明引用和服务端 Locator。解释引用字符串不是独立授权凭证，当前读取依然要检查主体和资源。

## 05｜来源目录怎样发行稳定引用？

读取 PgSourceReferenceDirectory.issue、固定字段顺序的元组摘要、当前文档授权、持久化与唯一约束。区分身份散列和权限判定。

## 06｜引用有效期与重新发行怎样工作？

分析活动引用不自动续期、过期后重新授权发行、resolve 不延长有效期，以及授权等待期间再次检查 TTL。

## 07｜资源授权与文档授权为什么分开？

使用对象服务和具体文档页面两种权限解释。沿 source.ts 的请求前后复核说明检查时点，限定为有界观察而非分布式事务。

## 08｜一份 Parsed Document 实际长什么样？

展示 Paddle 与 LandingAI 的解析输入、块结构和统一 ParsedSourceDocument。说明纯解析函数不执行网络请求，保留字段缺口和诊断位置。

## 09｜如何把解析页码映射到原始 PDF 物理页？

解释零基、一基、印刷页码与物理页。给出可运行映射示例和真实解析器的未知基准处理。pageMappingVerified 由已核验的版本映射产生。

## 10｜一页中的文字、表格和空白怎样返回？

分析块顺序、混合格式、多个 grounding、空页和缺页的差别。明确当前解析器对多页 grounding 采用首个定位并警告的范围。

## 11｜getSourcePage 怎样完成一次真实读取？

沿引用解析、版本核对、受控对象路径、解析、选页、输出 Schema 和最终授权复核展开。展示调用时序和正常、缺失、拒绝三种结果。

## 12｜缓存怎样保持来源版本与当前权限？

说明缓存键、读取前授权、返回前定位信息核对、只缓存可接受结果。缓存命中不能等价于重新取得上游数据，时间与版本语义按实际字段记录。

## 13｜多跳调用如何关联到 Harness 运行事实？

使用 ModelStep、ToolInvocation、resultItemRef 和 sourceRef 重建证据链。解释来源可追溯与模型语义使用正确的不同验证。

## 14｜枚举与多跳任务怎样表达覆盖范围？

展示目录分页、候选集合和待核验对象。区分 TopK 检索与全量遍历，说明 partial 覆盖不能泛化为全部产品结论。

## 15｜怎样验证来源身份、隔离、页码和缓存？

提供合成解析样本、元组身份测试、跨主体拒绝、到期竞争和缓存授权变化的测试矩阵。真实 PDF 核验依照已授权样本与版本证据。

## 16｜如何从回答反向查到原始来源？

提供只读 SQL 与接口读取顺序，核对 Invocation、结果、引用、文档版本和页码。讨论来源缺失时怎样保留事实与提示待核验项。

## 17｜可信多跳建立在每一次身份转换上

将来源链收束到最终 Harness 任务，连接工具注册与运行快照专题。
